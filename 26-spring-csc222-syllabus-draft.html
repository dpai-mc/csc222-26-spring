Course Description and Purpose

Course Description

CSC222: Programming and Algorithms II focuses on software engineering techniques, data structures (arrays, records, strings, linked lists, stacks, queues, hash tables), recursion, and object-oriented programming concepts. Students will learn to design, implement, test, and debug programs using modern object-oriented languages. This course builds on fundamental programming concepts and prepares students for advanced computer science coursework.

Why This Course?

Understanding data structures and algorithms is essential for every computer science professional. In this course, you'll develop the skills to write efficient, well-organized code that can handle real-world problems. Whether you're pursuing a career in software development, systems programming, or data science, the concepts you master here will directly apply to your work. Beyond the technical skills, you'll learn how to think algorithmically—to break down complex problems and design elegant solutions.

Suggestions for Success

Here's what successful students in this course do:

  • Start assignments early. Don't wait until the last day to begin. These programming assignments take time to debug and refine.
  • Practice, practice, practice. Programming is a skill learned by doing. Write code regularly, even outside of assignments.
  • Read the resources. The OpenDSA visualizations and online tutorials will deepen your understanding beyond what we cover in class.
  • Use office hours. Whether you're struggling or excelling, office hours are a great place to ask questions and discuss ideas.
  • Form study groups. Explaining concepts to peers is one of the best ways to solidify your own understanding.
  • Test your code thoroughly. Good programmers test edge cases and write test cases before they complete assignments.
  • Review feedback carefully. When I return your work, read my comments. They're designed to help you improve.
  • Don't compare yourself to others. Everyone learns at their own pace. Focus on your own progress.

Academic Honesty

You can succeed in this class through your own effort. Do not endanger your success by engaging in academic dishonesty. Academic honesty is a fundamental expectation in higher education. Violations include, but are not limited to:

  • Submitting work that is not your own
  • Copying code from other sources without attribution
  • Allowing others to submit your work
  • Using unauthorized resources during exams
  • Plagiarizing ideas, code, or writing without proper citation

For a full description of the College's Academic Honesty Policy, please see the College Catalog and contact the Instruction Office at (707) 468-3002 if you have questions.
